DevSecOps Kubernetes Training Lab Guide

Version: 2026 Edition · Verified against Kubernetes v1.36, Helm v4, the Gateway API (Ingress successor), Trivy, Kyverno, Cosign/Sigstore, Argo CD v3.x, and Falco v0.44.

This guide takes you from a basic understanding of containers to deploying, managing, and securing production-grade Kubernetes clusters. It follows a sectioned, zero-to-pro path and emphasizes DevSecOps principles, integrating security at every stage of the lifecycle.

The training is organized into four sections, numbered 0 to 3, plus a set of appendices:

  • Section 0: Setup. Local tooling, Minikube, kubeconfig, and setup verification.
  • Section 1: Foundations. Core concepts and the day-to-day kubectl skills every engineer needs.
  • Section 2: Production Operations. How real teams package, expose, scale, and operate workloads (Helm, Ingress, StatefulSets, observability, GitOps).
  • Section 3: DevSecOps Deep Dive. Shift-left scanning, admission control, RBAC, network policy, supply-chain security, policy-as-code, and runtime detection.

A note on scope. "Everything about Kubernetes" is genuinely a multi-week curriculum. This guide is a complete, hands-on spine, where each lab is runnable on a laptop with Minikube and maps to a real production practice. Where a topic is deep enough to deserve its own course (service meshes, multi-cluster, operators), we flag it and point you onward rather than pretend a single lab covers it.
